# data/competition-import

Approved location for competition dataset import inputs.

The Hackathon runtime import looks only for these files in this directory:

- `outlets.csv`
- `vehicles.csv`
- `calendar.csv`

Other files in this directory are not part of that runtime import. Datathon training, test, and submission files are not Hackathon runtime inputs and are not imported by that command.

Do not place secrets in this directory.
